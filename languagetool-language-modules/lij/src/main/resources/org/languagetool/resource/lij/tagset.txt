Tags are based on Universal Dependencies. We serialise UPOS and features into a single string, using a space as a separator both after the UPOS and between the individual features, e.g. `UPOS Feature1=Value1 Feature2=Value2`. Features are canonicalised by sorting them alphabetically, as per UD guidelines. Tags without features do not have a trailing space, e.g. `INTJ`.

We deviate from UD in the following two ways:
1. Articulated prepositions are tagged as a single token with POS `ADP+DET`, and retain the features of the article. They are assigned the singular masculine form as lemma, e.g. "a-e" has lemma `a-o`.
2. Verbs with attached clitics retain the base verb's lemma and features, and are given an additional `WithClitics` feature that records the attached clitic sequence, e.g. `WithClitics=selo`. The same approach is used for adverbs with attached clitics.
